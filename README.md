# AI-Powered Healthcare Cloud Data Platform

## Objective

Build a cloud-native healthcare data platform on AWS
with AI-powered analytics.

## Technologies

- Python
- SQL
- AWS S3
- AWS Glue
- PySpark
- Athena
- Redshift
- dbt
- Airflow
- Terraform
- Amazon Bedrock

## Project Status

The project is currently in its initial development stage. The foundational setup is underway, with plans to build a cloud-native healthcare data platform on AWS integrating data engineering, analytics, and AI-powered capabilities.

## Project Overview

This project demonstrates a cloud-native healthcare data platform built on AWS, integrating data engineering, analytics, and AI-powered capabilities.

## Architecture

The platform uses AWS services for data ingestion, transformation, storage, analytics, orchestration, and AI.

## Project Structure

- `ingestion/` – Data ingestion
- `transform/` – Data transformation
- `sql/` – SQL scripts
- `dbt/` – Data modeling
- `airflow/` – Workflow orchestration
- `infrastructure/` – Infrastructure as Code
- `dashboards/` – Analytics and dashboards
- `tests/` – Data quality and testing
